# 🔍 Auditr – Accounting Forensics & Fraud Detection System

## Overview

Auditr is an AI-powered accounting forensics and fraud detection platform developed to support auditors in identifying suspicious financial transactions through machine learning and explainable analytics.

The system combines automated fraud detection, interactive dashboards, and transaction-level explanations to assist users in reviewing financial records and prioritizing high-risk transactions for further investigation.

---

## Features

* Machine learning-based fraud detection for accounting transactions
* Interactive Streamlit interface for transaction analysis
* Explainable AI (XAI) to improve prediction transparency
* Dashboard visualizations for fraud monitoring and reporting
* Risk categorization and transaction filtering
* CSV upload and analysis workflow
* Human-in-the-loop decision support for auditors
